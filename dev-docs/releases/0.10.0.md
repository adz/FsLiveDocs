## FsLiveDocs 0.10.0

### Changed

- Package pages introduce the package with the project's `Description` (or `PackageDescription`) property. Previously the intro was the summary of the first documented entity when no entity was named exactly like the package, so a package such as `Reified.Constraint` opened with the text of its `Catalogue` module. The intro is now, in order: the summary of an entity named exactly like the package, then the project description, then nothing. Another entity's summary is never used.

### Compatibility

- The API artifact is schema 4. `PackageInfo` gains an optional `Description`. FsLiveDocs 0.10.0 still reads schema 3 capsules and history entries by an explicit migration that sets `Description` to none, so published releases keep rendering. Capsules written by 0.10.0 are schema 4 and cannot be read by earlier tool versions.
