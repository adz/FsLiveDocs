# FsLiveDocs 0.11.0

- API reference pages now organize compiler symbols into conceptual families. A same-named F# type and companion module share one reference experience while retaining stable symbol identities and anchors.
- API sections and facets can be authored in `docs/api/*.md` front matter or beside declarations with `<group>` and `<facet>` XML elements. Compiler-derived kind and signature-shape facets remain distinct from author intent.
- API organization is persisted as renderer-neutral release meaning in API schema 5. Schema 3 and 4 capsules migrate deterministically from their stored symbol graphs.
- FsLiveDocs now bundles checksum-pinned native Pagefind executables for Linux, macOS, and Windows on x64 and Arm64. Site and history builds no longer require Node.js, npm, `npx`, or a separate Pagefind installation.
