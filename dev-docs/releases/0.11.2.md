# FsLiveDocs 0.11.2

## Fixed

- Historical API version links use the actual generated file ID when related symbols share a display family. This repairs generic API links in older release capsules without relaxing history link verification or changing capsule data.
- Relative links to repository files use configurable source URLs, and local Markdown links resolve from their source paths before page slugs are applied. Broken links now report the resolved paths and all failures together.
- Cached builds invalidate when project inputs or compiled outputs change. Transcripts, run blocks, and snapshot examples bind to the documented project's assemblies and target framework rather than stale or tool-owned assemblies.
- Audits report every compiler error in a block and suggest module opens for uniquely identifiable API names. Builds warn when a configured project lacks XML documentation.

## Improved

- `init` chooses a useful default site name and can use an existing documentation README as the home page. Starter instructions now use `dotnet livedocs` and put setup steps first.
- Redirected builds use line-oriented progress so logs remain readable.
