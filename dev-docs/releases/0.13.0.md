# FsLiveDocs 0.13.0

## Added

- `headHtml` site config appends raw HTML to each page's `<head>`, for analytics, custom scripts, and other consumer snippets.
- `logoThemes` site config renders per-theme logo images keyed by daisyUI theme name, so a site can ship a logo whose background matches each theme's navbar.
- `scripts/build-logo.py` regenerates the FsLiveDocs logo assets from the same wordmark, colors, and timing as `LiveDocsBanner.fs`.

## Changed

- The FsLiveDocs site now uses an animated terminal logo: the CLI banner's block-reveal animation plays once per day in the navbar, with backgrounds matching each daisyUI theme.
- The CLI banner now carries the Fs prefix: the animated banner reveals "Fs Live Docs" and the static banner prints "FsLiveDocs".
