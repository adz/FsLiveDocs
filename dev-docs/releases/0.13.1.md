# FsLiveDocs 0.13.1

## Added

- Checked page examples show a collapsed **Requires & types** panel with compiler-derived opens, documented NuGet packages and top-level `let` signatures. Generated Markdown mirrors and `llms-full.txt` include the same information after each example.
- `fsharp no-context`, page front matter `exampleContext: false`, and site config `exampleContext: false` disable this annotation at the corresponding scope.

- F# examples show a textual status badge: **Verified**, **Fragment** (with the no-check reason), or **Isolated**. Markdown mirrors and LLM output include status comments. Set `exampleStatusBadges: false` in site config to hide HTML badges only.

- Hidden `prepare` blocks appear once as trimmed page setup in Markdown mirrors and `llms-full.txt`; the site offers a **Show page setup** toggle near the first checked block.

## Compatibility

- Semantic schema 3 and content schema 6 retain renderer-neutral example context and its opt-outs. Schema-2 semantic and schema-1–5 content artifacts migrate explicitly; cache keys include the new semantic schema version.
