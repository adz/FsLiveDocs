# FsLiveDocs 0.13.1

## Added

- Checked page examples show a collapsed **Requires & types** panel with compiler-derived opens, documented NuGet packages and top-level `let` signatures. Generated Markdown mirrors and `llms-full.txt` include the same information after each example.
- `fsharp no-context`, page front matter `exampleContext: false`, and site config `exampleContext: false` disable this annotation at the corresponding scope.

## Compatibility

- Semantic schema 3 and content schema 5 retain renderer-neutral example context and its opt-outs. Schema-2 semantic and schema-1–4 content artifacts migrate explicitly; cache keys include the new semantic schema version.
