# FsLiveDocs 0.14.0

## Added

- Checked examples show a collapsed **Requires & types** panel with compiler-derived opens, documented packages and top-level signatures. Markdown mirrors and `llms-full.txt` include the same context. `no-context` on a fence, page `exampleContext: false`, or site `exampleContext: false` disables it.
- F# examples display **Verified**, **Fragment**, **Isolated**, or setup status badges. Markdown mirrors and LLM output include status comments. Site `exampleStatusBadges: false` hides HTML badges.
- Hidden `prepare` blocks appear as trimmed page setup in Markdown mirrors and `llms-full.txt`, and in a **Show page setup** toggle on the site.

## Fixed

- Transcluded snippets and XML examples in Markdown mirrors and `llms-full.txt` now use the expanded, link-rewritten page body, so block identities and Requires/types match the HTML page.
- Status comments live inside code fences rather than leaking into blog excerpts, reading-time estimates, and RSS descriptions.
- `run` badges and mirror comments no longer claim a build or watch invocation executes examples; execution requires `test` or `capture`.
- Historical semantic-schema-2 capsules with no example context retain authored `open` statements in page setup instead of rendering incomplete setup.
- Requires lines separate opens from packages with one space.

## Compatibility

- Semantic schema 3 and content schema 6 retain renderer-neutral example context and opt-outs. Older artifacts migrate explicitly without recompilation or backfilling historical context.
