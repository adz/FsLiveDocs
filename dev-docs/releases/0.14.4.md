# FsLiveDocs 0.14.4

## Fixed

- Preserve authored `api.sections` organization from API enrichment pages in release capsules, so `build-history` renders the same grouped entity summaries, sidebars, and member sections as source builds.

Capsules are immutable and cannot be repaired after publication. Reified 0.11.0 and 0.11.1 were captured after their authored API sections were added but contain only generated default sections; recapture under a new Reified version is required. Axial added authored sections after 0.11.2, so no published Axial capsule lost them, but its next release must use this fix.
