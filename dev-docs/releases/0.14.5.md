# FsLiveDocs 0.14.5

## Fixed

- Resolve API extraction references through MSBuild's `ReferencePath` result, so framework references such as `Microsoft.AspNetCore.App` no longer leave FSharp.Formatting unable to resolve types like `Microsoft.AspNetCore.Http.HttpRequest`. The generated API model still contains only the documented project's own assemblies and namespaces.
- Compile pages without a `targetFramework` front-matter setting against their selected project's own references instead of the union of every selected project's target frameworks. Adding a net8-only project to a netstandard2.1 documentation set no longer changes what `System.Runtime` a guide resolves against.
- Render an API sidebar entity once when a package section names both the entity and one of its nested children, rather than recursively rendering the child under its parent and again as a section entry.
