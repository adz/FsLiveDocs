# FsLiveDocs 0.14.6

## Changed

- Built on Axial 0.16.0 and Reified 0.14.0, up from Axial 0.9.1 and Reified 0.8.0. `Axial.Layers` and
  `Axial.PlatformService` no longer exist, so the package no longer depends on them; `GH_TOKEN` for `history-sync` is
  read through `Axial.Configuration`'s environment source. Commands, output and persisted release artifacts are
  unchanged.

## Fixed

- `dotnet msbuild` evaluations run with `-nodeReuse:false`. A reusable MSBuild node kept the evaluation's output pipes
  open after it exited, and FsLiveDocs, which reads a process's output to the end, waited for that node to shut down.
