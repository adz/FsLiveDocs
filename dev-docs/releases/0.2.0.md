## FsLiveDocs 0.2.0

FsLiveDocs can now publish and host a complete versioned documentation site on GitHub Pages.

### Highlights

- Added GitHub Pages deployment and release-history rendering.
- Added generated GitHub Actions configuration with `livedocs generate-ci`.
- Added release capsule names in the form `<package>-<version>-livedocs.zip`.
- Fixed empty guide labels when rendering documentation capsules.
- Improved sidebar ordering for folder-driven documentation.
- Grouped generated API pages by NuGet `PackageId` instead of executable assembly name.
- Documented Tailwind CSS and DaisyUI themes and custom styling.
- Reworked the homepage and guides around complete-site usage and the differences from FSharp.Formatting.
- Corrected NuGet package licensing metadata to Apache-2.0.

### Breaking change

The CI workflow generator has a clearer name. Replace:

```bash
dotnet livedocs ci
```

with:

```bash
dotnet livedocs generate-ci
```
