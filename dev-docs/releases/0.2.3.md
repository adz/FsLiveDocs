## FsLiveDocs 0.2.3

FsLiveDocs release documentation now deploys automatically alongside package publication.

### Fixes

- Added the FsLiveDocs 0.2.0 capsule to the release-history index so the current site renders the latest published documentation.
- Dispatch GitHub Pages directly after creating an immutable GitHub release.
- Verify the dispatched documentation capsule by URL and SHA-256 before rendering.
- Preserve previous releases under versioned history paths.
