## FsLiveDocs 0.3.0

Fix nested ```fsharp fence rendering, version switcher label & docs

### Fixes

- Nested ```fsharp fenced blocks were not rendered properly.

- Fixed the version switcher which worked but always rendered as
  the latest regardless of displayed version.

- Reworded docs.

Note: this changes discovered block ordinals/IDs for pages using this
nested-fence pattern, so it will not correctly re-render the existing
0.1.0/0.2.0 release capsules...
