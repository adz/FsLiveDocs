## FsLiveDocs 0.3.1

Package navigation now opens package-specific API landing pages instead of shared namespace pages.

### Fixes

- Added distinct `/api/packages/<package>.html` routes for package landing pages.
- Fixed package links when a package name is also a namespace ID, such as `Axial.Telemetry`.
- Limited each package landing page to entities owned by that package while preserving the shared namespace page separately.
