## FsLiveDocs 0.3.4

Fix source parameter-name recovery missing every member declared inside a type's body.

### Fixes

- `SourceParameters` only read a `SynTypeDefn`'s outer `members` field, which holds only members
  added via a `type X with ...` augmentation. A type's own body members (`static member ...`
  declared directly in the type) live in `SynTypeDefnRepr.ObjectModel` instead, so their
  discard-pattern parameters (`_: T`) always fell back to a synthetic name and were wrongly
  flagged as `unnamed-parameter`. Both member lists are now walked.
