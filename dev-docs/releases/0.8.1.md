## FsLiveDocs 0.8.1

### Fixed

- `livedocs capture` no longer treats non-Markdown files in a documentation set as guide pages. Previously every file outside `api/` was scanned as a guide, so a set containing `logo.png` and `logo.svg` failed with `Documentation sets generate the same output path: logo.html`, and hand-written `.txt` files containing `fsharp` fences failed with `Semantic artifact is missing block <set>/llms.txt#fsharp-0`. Images, text files, and other assets are now copied as static files only. `livedocs build` was not affected.
