## FsLiveDocs 0.9.0

### Performance

- Documentation pages are checked together in generated, page-isolated F# projects instead of as unrelated one-file scripts. On the FsLiveDocs documentation build this reduced a clean build from 18.58 seconds to 9.00 seconds and a semantic-cold build from 11.85 seconds to 6.51 seconds.
- Semantic compiler artifacts are cached per documentation page, so editing one page no longer recompiles unrelated pages.
- API extraction is cached independently per project and no longer invalidated by ordinary documentation edits. Generated-example verification retains its own documentation-sensitive cache.
- Builds persist a content-hashed input manifest. Restarting `livedocs` with no changes now reuses the complete rendered site and search index instead of repeating extraction, compilation, rendering, and Pagefind.
- Compiler diagnostics for isolated examples are projected and released incrementally instead of retaining every F# Compiler Service result graph until the complete batch finishes.

### Reliability

- Pagefind failures now fail `livedocs build` rather than leaving a successful-looking build with a missing or stale search index.
