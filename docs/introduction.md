# 🚀 Getting Started with FsLiveDocs

FsLiveDocs is a documentation engine built specifically for the F# ecosystem.
 It bridges the gap between your code and your guides by ensuring every example is verified against your actual implementation.

## 🏗 Why FsLiveDocs?

Most documentation systems suffer from **documentation rot**. Code changes, but examples in Markdown files are forgotten. FsLiveDocs treats your documentation as a first-class citizen:

1.  **Verified Docstrings**: Your `/// <example>` tags are extracted and executed as tests.
2.  **Live Transclusion**: Pull code directly from your `.fs` files into your guides.
3.  **No Node.js**: A pure .NET tool that works natively in your environment.
4.  **Multi-Project Merging**: Generate a single unified site for your entire solution.

## 🧪 Worked Example

Let's say you have a simple math library. You can document it like this:

```fsharp
namespace MyLib

module Math =
    /// <summary>Adds two numbers together.</summary>
    /// <example name="BasicAdd">
    /// let result = Math.add 10 20
    /// printfn "%d" result
    /// // EXPECTED: 30
    /// </example>
    let add x y = x + y
```

### 1. Initialize your project
Run the `init` command to scaffold the folder structure.
```bash
livedocs init
```

### 2. Verify and Build
The `preview.sh` script (or `build` command) will now find that example, run it, and generate a beautiful site.

```bash
./scripts/preview.sh
```

### 3. See the Result
Your documentation will now feature a **Verified Example** card. If you change `add` to be a multiplication by mistake, the next build will **FAIL**, preventing you from publishing incorrect docs.

## 🎨 Professional Styling

Every site generated by FsLiveDocs uses **Tailwind CSS** and **DaisyUI**. You can swap the look of your entire documentation with a single flag:

```bash
livedocs build MyProject.fsproj --theme cupcake
```
